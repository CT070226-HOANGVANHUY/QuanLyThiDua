Sao lưu dữ liệu

Giữ một bản trên USB để máy hỏng không mất số thi đua.

Nên sao lưu sau mỗi buổi nhập tuần. File nằm trên máy này; USB là bản dự phòng.

1. Cất bản sao

{% if last_backup_at %}

Lần gần nhất: {{ last_backup_at }}

{% else %}

Chưa cất lần nào trên máy này.

{% endif %}

Có thể ghi đường dẫn thư mục USB. Để trống nếu chỉ muốn bản trong máy.

2. Lấy lại dữ liệu đã cất

Chọn file đã sao lưu. Toàn bộ số liệu hiện tại trên máy sẽ bị thay bằng bản đó. Làm khi đổi máy hoặc khi lỡ xóa nhầm.

2. Lấy lại dữ liệu (khi mở bằng trình duyệt)

Đóng phần mềm. Nhờ người phụ trách máy copy file đã sao lưu đè vào thư mục dữ liệu của phần mềm, rồi mở lại.

Nếu dùng cửa sổ Thi đua (chay-app), nút chọn file hiện sẵn — không cần làm tay.
