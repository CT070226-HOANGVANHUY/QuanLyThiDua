Phục hồi

Chọn file .db đã sao lưu. Ứng dụng kiểm tra file, thay dữ liệu hiện tại, xóa -wal/-shm, rồi khởi động lại.

Phục hồi thủ công

Khi mở bằng chay.bat không có nút Phục hồi in-app. Đóng ứng dụng rồi:

  1. Sao chép file .db vào data/thidua.db (thay file hiện tại).
  2. Xóa data/thidua.db-wal và data/thidua.db-shm nếu có.
  3. Nếu kèm thư mục BaoCao, chép đè vào thư mục BaoCao của ứng dụng.
  4. Chạy lại chay.bat.

File có user_version lớn hơn ứng dụng sẽ bị từ chối khi kiểm tra. File cũ hơn được nâng schema lúc mở.
